# ORBIT brand assets

| File | Use |
|---|---|
| `orbit-icon.png` (1024×1024) | GitHub repository avatar / app icon |
| `orbit-icon-512.png` | Smaller avatar, integrations |
| `orbit-icon.svg` | Vector icon for the web app and docs |
| `orbit-logo.png` (1600×400) | README/docs wordmark, light and dark backgrounds |
| `orbit-social-preview.png` (1280×640) | GitHub **Settings → Social preview** |

## GitHub setup

1. **Repository avatar**: Settings → General → Social preview/avatar, upload
   `orbit-icon.png`.
2. **Social preview**: Settings → General → Social preview, upload
   `orbit-social-preview.png`.
3. The README uses `orbit-logo.png`; keep the files at these paths so links stay valid.

## Palette

| Token | Hex |
|---|---|
| Orbit violet | `#7C6CFF` |
| Orbit light | `#A894FF` |
| Ink / background | `#0B0B12` |
| Muted text | `#C4C2D6` |

Keep the mark on dark backgrounds for contrast. The icon is transparent outside the rounded
square, so it works on GitHub light and dark themes.
